# Changelog

All notable changes to the **SrikanthMart** platform will be documented in this file.

- **v1.1.0** (Oct 10, 2026): Shipped AI Chatbot integration (`ChatController`, `ChatService`, `GeminiChatProvider`, `MockChatProvider`) with session rate limiting and caching.
- **v1.0.0** (Sep 21, 2026): Live cloud deployment finalized with Nginx TLS reverse proxy, systemd daemon, and Docker multi-stage build.
- **v0.5.0** (Sep 6, 2026): Implemented product reviews, star ratings on completed orders, and input validation layer.
- **v0.4.0** (Aug 30, 2026): Added product search/filter engine and multi-step order workflow (`Pending` -> `Confirmed` -> `Shipped` -> `Delivered`).
- **v0.3.0** (Aug 23, 2026): Added seller sales dashboard with revenue metrics and admin central management panel.
- **v0.2.0** (Aug 16, 2026): Implemented seller product listing desk (create, edit, delete listings) and incoming orders view.
- **v0.1.0** (Aug 10, 2026): Delivered working MVP demo featuring user authentication, catalog browsing, shopping cart, and mock checkout.
- **v0.0.1** (Jul 27, 2026): Project initialized with C++20 Drogon skeleton, vcpkg manifest, SQLite RAII repository, and V1 database migration.
